# Projet-programmation-web-M1-IDL-UGA

Projet Programmation Web 
Master 1 IdL – S1 – année 2025-2026
Camille Benoit-Guyod, Ekaterina Leonova, Ombeline Ulbrich-Cloppet, Darya Zdrelyuk, Jiahong Zhang

Travail réalisé dans le projet :
Le projet consiste en la création d’une plateforme de révision du français pour le primaire, organisée par compétences : grammaire, vocabulaire, conjugaison, orthographe et lecture.
Le projet est hébergé sur GitHub, ce qui permet le suivi des versions et l’accès aux contributions de chaque membre du groupe. (https://github.com/daryazdr/Projet-programmation-web-M1-IDL-UGA/tree/revision-plateforme) 

Le travail a été réparti entre les membres du groupe, chacun étant responsable d’une partie précise :
Camille Benoit-Guyod :
Création des pages de grammaire. Mise en place des exercices correspondants et participation à la mise en forme générale du site via le CSS commun.
Ekaterina Leonova :
Création des pages de conjugaison. Développement des exercices interactifs (QCM, réponses écrites), vérification automatique des réponses et calcul des scores en JavaScript.
Ombeline Ulbrich-Cloppet :
Création des pages d’orthographe. Développement des scripts JavaScript liés au calcul du score global et à sa réinitialisation sur l’ensemble de la plateforme.
Darya Zdrelyuk :
Création des pages de lecture. Developpement de la page de vocabulaire. Organisation du dépôt GitHub. Gestion du versionnement, explications du fonctionnement de Git au groupe.
Jiahong Zhang :
Création des pages de vocabulaire. Développement d’activités interactives, notamment des exercices de type glisser-déposer avec supports visuels.

Fonctionnalités globales du site :
Navigation commune entre toutes les section
Exercices interactifs variés (QCM, réponses écrites, glisser-déposer)
Feedback immédiat pour chaque activité
Calcul d’un score par exercice et d’un score global
Code structuré (HTML / CSS / JavaScript séparés). Nous avons fait le choix de créer des feuilles de style spécifiques à chaque page d’exercice en plus de la CSS commune à tout le site afin que cette dernière reste lisible et pour faciliter la personnalisation de nos exercices. Nous avons ensuite veillé à ce que les CSS n’entrent pas en conflit pour chaque page du site.
